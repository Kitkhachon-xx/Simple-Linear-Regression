# KNN Regressor: การคำนวณหาค่า Error อย่างละเอียด

อ้างอิงจาก `02-Code-Station/Python/Knn-Regressor.py` และต่อยอดแนวคิด error แบบเดียวกับที่ `Linear_Regression.ipynb` ใช้ในเซกชัน "Loop For Add a Power" (`e = np.mean(np.abs(Y - j))`)

## ทำไมต้องปรับโค้ดก่อนคำนวณ error

โค้ดต้นฉบับ query ที่จุด `i = [0, 1]` ซึ่งไม่มี $Y$ จริงคู่กัน จึงคำนวณ error ตรง ๆ ไม่ได้ ต้องเปลี่ยนให้ query point คือ $X_n$ เดิมในข้อมูลฝึก และ**ตัดตัวเองออกจากการหาเพื่อนบ้าน (Leave-One-Out)** ไม่อย่างนั้นแต่ละจุดจะมีระยะทาง $d_n = |X_n - X_n| = 0$ เลือกตัวเองเป็นเพื่อนบ้านเสมอ ทำให้ error ต่ำผิดปกติ (ที่ $k=1$ จะได้ error = 0 เสมอ ซึ่งไม่สะท้อนความสามารถจริงของโมเดล)

```python
o = []
for n in range(len(X)):
    d = np.abs(X - X[n])
    d[n] = np.inf              # ตัดตัวเองออก
    d_s = np.argsort(d)[:k]
    o.append(np.mean(Y[d_s]))

o = np.array(o)
e_mae = np.mean(np.abs(Y - o))
e_mse = np.mean((Y - o) ** 2)
e_rmse = np.sqrt(e_mse)
```

## สูตร Error

$$e_{MAE} = \frac{1}{N}\sum_{n=1}^{N} |Y_n - \hat{y}_n| \qquad
e_{MSE} = \frac{1}{N}\sum_{n=1}^{N} (Y_n - \hat{y}_n)^2 \qquad
e_{RMSE} = \sqrt{e_{MSE}}$$

โดย $\hat{y}_n$ คือค่าที่ KNN ทำนายให้กับจุด $X_n$ (จากขั้นตอน Leave-One-Out ด้านบน)

---

## ตัวอย่างตัวเลข (ต่อจากชุดข้อมูลเดิม)

ใช้ชุดข้อมูลจำลอง $N=6$, $k=3$ เหมือนตัวอย่างก่อนหน้า:

| index $n$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $X_n$ | 0.10 | 0.35 | 0.40 | 0.50 | 0.80 | 0.90 |
| $Y_n$ | 1.6 | 3.1 | 3.5 | 4.0 | 5.8 | 6.5 |

### ขั้นที่ 1: หาค่าทำนาย $\hat{y}_n$ ของทุกจุดแบบ Leave-One-Out

**n = 0** ($X_0 = 0.10$): $d = |X - 0.10| = [0,\ 0.25,\ 0.30,\ 0.40,\ 0.70,\ 0.80]$ → ตัดตัวเอง ($d_0=\infty$) → 3 ใกล้สุด: index $[1,2,3]$ → $Y = [3.1, 3.5, 4.0]$
$$\hat{y}_0 = \frac{3.1+3.5+4.0}{3} = \frac{10.6}{3} \approx 3.533$$

**n = 1** ($X_1 = 0.35$): $d = [0.25,\ 0,\ 0.05,\ 0.15,\ 0.45,\ 0.55]$ → ตัดตัวเอง → 3 ใกล้สุด: index $[2,3,0]$ → $Y=[3.5,4.0,1.6]$
$$\hat{y}_1 = \frac{3.5+4.0+1.6}{3} = \frac{9.1}{3} \approx 3.033$$

**n = 2** ($X_2 = 0.40$): $d = [0.30,\ 0.05,\ 0,\ 0.10,\ 0.40,\ 0.50]$ → ตัดตัวเอง → 3 ใกล้สุด: index $[1,3,0]$ → $Y=[3.1,4.0,1.6]$
$$\hat{y}_2 = \frac{3.1+4.0+1.6}{3} = \frac{8.7}{3} = 2.900$$

**n = 3** ($X_3 = 0.50$): $d = [0.40,\ 0.15,\ 0.10,\ 0,\ 0.30,\ 0.40]$ → ตัดตัวเอง → 3 ใกล้สุด: index $[2,1,4]$ → $Y=[3.5,3.1,5.8]$
$$\hat{y}_3 = \frac{3.5+3.1+5.8}{3} = \frac{12.4}{3} \approx 4.133$$

**n = 4** ($X_4 = 0.80$): $d = [0.70,\ 0.45,\ 0.40,\ 0.30,\ 0,\ 0.10]$ → ตัดตัวเอง → 3 ใกล้สุด: index $[5,3,2]$ → $Y=[6.5,4.0,3.5]$
$$\hat{y}_4 = \frac{6.5+4.0+3.5}{3} = \frac{14.0}{3} \approx 4.667$$

**n = 5** ($X_5 = 0.90$): $d = [0.80,\ 0.55,\ 0.50,\ 0.40,\ 0.10,\ 0]$ → ตัดตัวเอง → 3 ใกล้สุด: index $[4,3,2]$ → $Y=[5.8,4.0,3.5]$
$$\hat{y}_5 = \frac{5.8+4.0+3.5}{3} = \frac{13.3}{3} \approx 4.433$$

### ขั้นที่ 2: รวบรวมค่าจริง vs ค่าทำนาย

| $n$ | $Y_n$ (จริง) | $\hat{y}_n$ (ทำนาย) | $Y_n - \hat{y}_n$ | $\lvert Y_n - \hat{y}_n \rvert$ | $(Y_n - \hat{y}_n)^2$ |
|---|---|---|---|---|---|
| 0 | 1.6 | 3.533 | -1.933 | 1.933 | 3.738 |
| 1 | 3.1 | 3.033 | 0.067 | 0.067 | 0.004 |
| 2 | 3.5 | 2.900 | 0.600 | 0.600 | 0.360 |
| 3 | 4.0 | 4.133 | -0.133 | 0.133 | 0.018 |
| 4 | 5.8 | 4.667 | 1.133 | 1.133 | 1.284 |
| 5 | 6.5 | 4.433 | 2.067 | 2.067 | 4.271 |

### ขั้นที่ 3: รวมและหาค่าเฉลี่ย

**MAE**
$$e_{MAE} = \frac{1.933+0.067+0.600+0.133+1.133+2.067}{6} = \frac{5.933}{6} \approx 0.989$$

**MSE**
$$e_{MSE} = \frac{3.738+0.004+0.360+0.018+1.284+4.271}{6} = \frac{9.676}{6} \approx 1.613$$

**RMSE**
$$e_{RMSE} = \sqrt{1.613} \approx 1.270$$

---

## สังเกตความหมายของผลลัพธ์

- จุดที่ index 0 และ 5 (หัว-ท้ายของช่วงข้อมูล) มี error สูงสุด ($|Y-\hat{y}| \approx 1.93$ และ $2.07$) เพราะเป็นจุดปลายสุด (boundary point) — เพื่อนบ้านที่ใกล้ที่สุด 3 ตัวของมันอยู่ **ด้านเดียว** (ด้านในของช่วงข้อมูล) เท่านั้น ทำให้ค่าเฉลี่ยเบี่ยงเข้าหากึ่งกลางของข้อมูล ไม่สะท้อนแนวโน้มที่ปลายสุดจริง ๆ — ปัญหานี้เรียกว่า **boundary/edge effect** ของ KNN
- จุดกลาง ๆ (index 1,2,3) มี error ต่ำกว่ามาก เพราะมีเพื่อนบ้านล้อมรอบทั้งสองด้าน
- ค่าที่ได้ (MAE ≈ 0.989, RMSE ≈ 1.270) ใช้เปรียบเทียบกับค่า error ของโมเดลอื่น (เช่น Polynomial Regression ในโน้ตบุ๊กหลัก) หรือใช้เปรียบเทียบระหว่างค่า `k` ต่าง ๆ เพื่อเลือก `k` ที่ให้ error ต่ำที่สุด (คล้ายกับที่ลูป `for M in range(4, 15)` หา degree ที่ดีที่สุดในเซกชัน Polynomial)
