# KNN Regressor: ตัวอย่างตัวเลขประกอบการคำนวณ

ตัวอย่างนี้อ้างอิงโค้ดจาก `02-Code-Station/Python/Knn-Regressor.py`:

```python
for t in i :
    d = np.abs(X - t)
    d_s = np.argsort(d)[:k]
    o.append(np.mean(Y[d_s]))
```

ใช้ข้อมูลจำลองเล็ก ๆ ที่มี $N=6$ จุด และ $k=3$ (แทนของจริงที่มี $N=50$) เพื่อให้เห็นตัวเลขจริงในทุกขั้นตอน

## ข้อมูลตั้งต้น

| index $n$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $X_n$ | 0.10 | 0.35 | 0.40 | 0.50 | 0.80 | 0.90 |
| $Y_n$ | 1.6 | 3.1 | 3.5 | 4.0 | 5.8 | 6.5 |

`k = 3`, query points `i = [0, 1]`

---

## รอบที่ 1: `t = 0`

**บรรทัด `d = np.abs(X - t)`**

$$d_n = |X_n - 0|$$

| index $n$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $d_n$ | 0.10 | 0.35 | 0.40 | 0.50 | 0.80 | 0.90 |

**บรรทัด `d_s = np.argsort(d)[:k]`**

เรียงตาม $d_n$ จากน้อยไปมาก แล้วเอาแค่ 3 ดัชนีแรก:

$$d_s = [0,\ 1,\ 2] \quad (\text{ระยะทาง } 0.10,\ 0.35,\ 0.40)$$

**บรรทัด `Y[d_s]`**

ดึงค่า $Y$ ที่ตำแหน่ง 0, 1, 2 ออกมา:

$$Y[d_s] = [1.6,\ 3.1,\ 3.5]$$

**บรรทัด `np.mean(Y[d_s])`**

$$\hat{y}(0) = \frac{1.6 + 3.1 + 3.5}{3} = \frac{8.2}{3} \approx 2.733$$

→ `o = [2.733]`

---

## รอบที่ 2: `t = 1`

**`d = np.abs(X - 1)`**

$$d_n = |X_n - 1|$$

| index $n$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $X_n$ | 0.10 | 0.35 | 0.40 | 0.50 | 0.80 | 0.90 |
| $d_n$ | 0.90 | 0.65 | 0.60 | 0.50 | 0.20 | 0.10 |

**`d_s = np.argsort(d)[:k]`**

รอบนี้ index ที่มีค่า $d_n$ น้อยที่สุดกลับเป็นด้านขวาของ array (เพราะจุดใกล้ $t=1$ คือ $X_n$ ที่มีค่าเข้าใกล้ 1) เรียงจากน้อยไปมาก: $d_5=0.10,\ d_4=0.20,\ d_3=0.50,\ d_2=0.60,\ d_1=0.65,\ d_0=0.90$ → ตัดเอา 3 อันดับแรก:

$$d_s = [5,\ 4,\ 3]$$

**`Y[d_s]`**

$$Y[d_s] = [6.5,\ 5.8,\ 4.0]$$

**`np.mean(Y[d_s])`**

$$\hat{y}(1) = \frac{6.5 + 5.8 + 4.0}{3} = \frac{16.3}{3} \approx 5.433$$

→ `o = [2.733, 5.433]`

---

## สรุปผล

| Query point $t$ | 3 เพื่อนบ้านที่ใกล้ที่สุด (index) | ค่า $Y$ ของเพื่อนบ้าน | $\hat{y}(t)$ |
| --------------- | --------------------------------- | --------------------- | ------------ |
| 0               | 0, 1, 2                           | 1.6, 3.1, 3.5         | **2.733**    |
| 1               | 5, 4, 3                           | 6.5, 5.8, 4.0         | **5.433**    |

จุดสำคัญที่เห็นจากตัวเลข: `d_s` เป็นแค่ "ตำแหน่งอ้างอิง" (index) — มันเปลี่ยนไปตามว่า query point อยู่ตรงไหน (รอบแรกชี้ไป index 0,1,2 รอบสองชี้ไป index 5,4,3) แล้ว `Y[d_s]` ใช้ตำแหน่งนั้นไปดึงค่า $Y$ จริงออกมาเฉลี่ยเป็นคำตอบสุดท้าย ไม่ได้เอาตัวเลขใน `d_s` (0,1,2 หรือ 5,4,3) มาคำนวณตรง ๆ
